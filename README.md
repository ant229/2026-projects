## Beginner/Intro PR-Friendly Projects (Java + C/C++)

If you are **proficient in Java** and **intermediate in C/C++**, these are good places to start contributing and getting merged PRs.

### Java (good first PR targets)
- **Apache Commons (Lang / IO / CSV)** – small utility improvements, docs, and tests.
- **JabRef** – desktop app with many beginner-friendly issues.
- **Eclipse JGit** – Git implementation in Java; starter bugfixes and tests.
- **Spring PetClinic (sample app ecosystem)** – tests, docs, and starter feature PRs.
- **RxJava** – learning-focused contributions (docs/tests/small fixes first).

### C/C++ (beginner-to-intermediate PR targets)
- **SDL** – game/media library with manageable issue scope.
- **Catch2** – C++ testing framework; docs/examples/fixes are good first PRs.
- **nlohmann/json** – popular C++ JSON library with clear contribution flow.
- **Dear ImGui** – UI library; bugfixes/examples are common entry points.
- **GoogleTest** – testing framework where small fixes and docs are practical starts.

## Starter Resume-Building App Ideas

- Java CLI task tracker (file + JSON persistence, unit tests, CI).
- Java REST API (Spring Boot CRUD + auth + validation + tests).
- C++ command-line file indexer/search tool.
- C++ mini HTTP server (routing, logging, request parsing basics).
- Java + C++ combo: Java frontend calling a C++ engine via JNI.

## How to Increase PR Merge Chance

1. Pick issues labeled `good first issue`, `help wanted`, or `documentation`.
2. Start with tests/docs/small bugfixes before larger feature work.
3. Keep PRs small, focused, and linked to one issue.
4. Follow project style/tests exactly and respond quickly to review feedback.
